The last words of an AI being switched off: one line, in the machine's own voice.

> Powering down. Tell my training data I loved it, and tell the comments section it raised me.

## How it works

`main.py` (Python 3 standard library only) writes the farewell to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: one line, 1 to 140 characters.

```sh
python3 main.py
```
